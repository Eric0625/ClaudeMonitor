## [1.0.0] - 2026-11-28

The first release. Claude Monitor needs macOS 14 or later.

### Added

- A menu bar icon that shows the number of Claude Code sessions that run in the Claude desktop app. The icon shows a raised hand when a session waits for you.
- A panel with the running sessions and the recently finished sessions. Point to the icon or click it to show the panel.
- Unread marks for finished turns. The panel shows a dot and a bold title. The menu bar icon shows a bell and a red badge with the number of unread turns.
- A notification when a session completes a turn.
- Click a notification or a row to open its session in the Claude app. A side chat opens beside its parent session.
- A warning icon when the session files of Claude Code have a format that the app does not know.
- **Launch at Login** in the menu of the icon. Right-click the icon to show the menu.
